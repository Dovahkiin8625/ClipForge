ClipForge · 使用说明
========================================

【怎么打开】
  双击 dist 文件夹里的「ClipForge.exe」即可，无需安装，也不需要 Python。

【它是干什么的】
  ClipForge 是一款音视频处理工具箱。核心功能包括把分开的「视频」和「音频」合成一个完整视频，
  以及音频提取、视频剪辑（可视化截段）、视频拼接、画面调整（旋转 / 裁剪 / 调色）、
  格式转换（视频 / 音频互转，支持导出 GIF 动图）、视频下载等。

【单个合并】三步
  1. 选「视频文件」和「音频文件」：点「浏览…」，或直接把文件拖进窗口任意位置（会自动识别哪个是视频、哪个是音频）。
  2. 确认「输出文件」：程序会自动填「原视频名_合并.mp4」，也可以点「另存为…」自己指定。
  3. 点「开始合并」，进度条走完即完成，日志区会显示输出大小和时长。

【批量合并】
  1. 点「扫描文件夹…」，选择一个放着多组视频 / 音频的文件夹（只扫这一层，不递归子文件夹）。
  2. 程序自动配对的默认逻辑是「文件名 + 时长」结合：文件名越像、时长越接近，就越配成一对；
     文件名完全一致的优先级最高；个别时长读不到的文件退回按文件修改时间就近配对。
  3. 列表里逐行显示视频、音频、各自时长和状态。配得不对可以手动调整：
     · 在列表里把某一行直接拖到另一行上，就把该行音频移了过去（两行都有音频则互相交换）；
     · 也可以从资源管理器把音频文件直接拖到某一行为它补配音频；
     · 拿不准的行取消勾选即可跳过。
  4. 核对无误就点「开始批量合并」，输出文件保存在各自视频所在目录，命名同样是「原视频名_合并.mp4」。
  提示：直接把一个文件夹拖进窗口，也会自动进入批量模式。
  注意：合并进行中不能拖动调整；先等结束或点「停止」。

【音频提取】
  1. 切到「音频提取」页，选一个视频文件（也是点「浏览…」或直接拖进窗口）。
  2. 设置：可指定提取第几路音频（多音轨视频还能自动挑音质最高的一路）、输出格式（MP3 / M4A / WAV / FLAC / OGG）和音质。
  3. 点「开始提取」即可，进度条和日志都在本页显示。
  省心细节：
  · 输出格式选「MP3」等有损格式时，若源编码能直接塞进该格式就会「原样复制」不再重压（比如源是 MP3 提回 MP3）；
  · WAV / FLAC 是无损格式，音质选项对它们不生效；
  · 输出文件默认自动命名「原视频名_音频.格式」，保存在视频所在目录。
  提示：提取只动声音，不碰画面，也不会修改原始视频。

【视频剪辑】
  1. 切到「视频剪辑」页，选一个视频文件（点「浏览…」或直接拖进来），程序会读取时长并自动铺设缩略图。
  2. 可视化选段（推荐）：
     · 左侧是当前画面的预览，拖动右侧缩略图滑块上的「播放头」即可点击 / 拖动定位画面；
     · 缩略图条两端各有一个白色把手，拖动它们即框选剪辑区间，选中的区间会高亮显示；
     · 也可以把画面定位好后点「设为开始」「设为结尾」两个按钮来定区间；
     · 「◀ 0.2秒 / 0.2秒 ▶」可小步微调当前位置；
     · 起止时间会实时同步到「开始 / 结束」两个输入框（格式 00:00:00 或 00:00，可带小数秒，
       如 00:01:30.5）；结束留空表示剪到视频结尾。下方会实时提示将截取的时长。
  3. 剪辑方式二选一：
     · 快速剪裁（默认）：直接复制流，无损且几秒完成；按起始处最近的关键帧截取，
        起止点可能有零点几秒的偏差。
     · 精确剪裁：重新编码，起止点精确，速度较慢。
  4. 输出默认「视频名_剪辑.mp4」，保存在源视频所在目录，可点「另存为…」修改。
  提示：剪辑只生成新文件，不会修改原始视频。

【画面调整】
  1. 切到「画面调整」页，选一个视频文件（点「浏览…」或直接拖进来），程序会自动抓取一帧画面作预览。
  2. 可视化实时预览（所见即所得）：
     · 左边是当前取样点的原始画面（拖动画面下方的滑块可以换一帧取样）；裁剪时画面上会画出红色虚线框，
       框内就是裁剪后保留的区域；
     · 右边是套用全部调整后的效果预览，旋转 / 镜像 / 缩放 / 裁剪 / 调色任一参数一变就立刻刷新；
     · 右上角文字实时显示「输出尺寸」和已启用的调整项；缩放自动保持宽高比、不足处补黑边。
  3. 调整项（全部不动 = 输出与源相同）：
     · 旋转 90° / 180° / 270°，水平镜像，垂直翻转；
     · 缩放到 1920×1080 / 1280×720 / 854×480 / 640×360；
     · 四边裁剪（各裁掉几个像素，0 = 不裁）；
     · 亮度 / 对比度 / 饱和度：拖滑杆调节（0 表示不变，范围约 -1.0 ~ +1.0）。
  4. 输出默认「视频名_画面.mp4」，保存在视频所在目录，可点「另存为…」修改。
  提示：预览为近似效果，最终以输出文件为准；输出会重编码为 H.264 + AAC（音频保留并转 AAC）；
  处理只生成新文件，不会修改原始视频。

【打开输出目录】
  每个功能页的执行区都有「打开输出目录」按钮：优先打开输出文件所在文件夹，
  还没指定输出时则打开源文件所在文件夹（视频拼接页会打开第一个片段所在文件夹）。

【视频拼接】
  1. 切到「视频拼接」页，点「添加视频片段…」或把多个视频文件直接拖进列表；
     用「上移 / 下移」调整先后顺序，「移除选中 / 清空」管理列表。
  2. 拼接方式二选一：
     · 直接拼接（默认）：不重新编码，最快速无损。开始前程序会核对各片段的编码、分辨率、帧率、
       时间基以及音频编码 / 采样率 / 声道，全部一致才直接拼接；只要有一项不一致就弹窗说明差异并拒绝直接拼
       （否则会出现后半段加速、花屏或音画不同步），可一键改用「统一转码拼接」。
     · 统一转码拼接：自动把所有片段统一成 H.264 + AAC，并按「时长最长的片段」的分辨率和帧率对齐
       （最长的片段一般是主体内容，也避免短小的高分辨率片段把整段放大、拖慢转码）；
       宽高比不同的片段按比例缩放并补黑边，不拉伸变形。兼容性最好，速度较慢。
  3. 输出默认保存在第一个片段所在目录，命名「第一个片段名_拼接.mp4」，可修改。
  推荐流程：先在「视频剪辑」页把需要的片段逐个截出来，再拿到这里按顺序拼接。

【格式转换】
  1. 切到「格式转换」页，选一个视频或音频文件（点「浏览…」或直接拖进来）。
  2. 选「目标格式」和参数（不同格式会自动过滤不相关的选项）：
     · 视频互转（MP4 / MKV / MOV / AVI / WEBM）：画质档对应 CRF（高 18 / 均 23 / 小 28）；
       音频可选原样复制或转 AAC；可选缩放到指定分辨率（自动保持宽高比，不足补黑边）；
     · 转纯音频（MP3 / M4A / WAV / FLAC）：自动忽略画面选项，画质档改选音频码率（320 / 192 / 128 kbps，
       WAV / FLAC 为无损）；
     · 转 GIF 动图：无声音；画质档对应帧率（高 15 / 均 12 / 小 8 fps）；分辨率可选，保持原样时
       源画面超过 640 宽会自动缩到 640 宽以控制体积；使用内置调色板（palettegen）保证颜色过渡自然。
       注意 GIF 是逐帧存储，文件明显大于普通视频，长片段建议选「体积最小」档。
  3. 「快速转换」只换封装格式、不重新编码，速度最快，但要求源编码与目标格式兼容
     （选 GIF / 纯音频格式时该选项自动禁用；勾了快速转换时「分辨率」不能缩放，会被忽略）。
  4. 输出默认「原文件名_转换.新格式」，保存在源文件所在目录，可点「另存为…」修改。
  提示：处理只生成新文件，不会修改原始文件；GIF 转回 MP4 / MKV 也可以（把 GIF 拖进来即可）。

【合并方式怎么选】
  · 直接复制音视频流（推荐）：不重新编码，质量无损，几秒完成。绝大多数 MP4 / MKV 都适用。
  · 视频原样复制，音频转成 AAC：视频不动，只把音频重新编码。音频格式和 MP4 不兼容时用。
  · 全部重新编码为 H.264 + AAC：前两种报错时用，兼容性最好，但慢，画质有轻微损失。

【会不会动到原始文件】
  不会。程序只读取源视频和源音频，只写你指定的输出文件；如果输出路径和源文件同名会被拦下来。
  合并失败或被停止时，程序会自动删掉自己生成的那个半成品文件（不会删你原本的文件）。

【如果提示找不到 ffmpeg】
  本工具靠 ffmpeg 干活。程序启动时自动在系统里查找；找不到时，点「指定 ffmpeg」选中 ffmpeg.exe 即可，
  路径会记在 dist\settings.ini，下次不用再选。也可以把 ffmpeg 放进 dist 或 dist\lib 文件夹里。

【视频下载】
  1. 切到「视频下载」页，粘贴视频链接（支持 http/https）。
  2. 选择下载方式：
     · 自动识别（推荐）：链接里包含 .m3u8 时自动使用 N_m3u8DL-CLI 下载合并；其它链接使用 ffmpeg 直接保存。
     · m3u8（使用 N_m3u8DL-CLI）：专用于 m3u8/HLS 流，会自动下载分片并合并为 MP4。
     · 直接下载（使用 ffmpeg）：适合普通直链视频/音频地址。
  3. 设置保存目录和文件名，点「开始下载」。进度和日志显示在本页。
  4. 「下载记录」会保存每次下载的时间、文件、方式、状态、大小和链接（保存在 dist\download_history.txt）：
     · 可重新下载、打开文件/所在目录、复制链接、删除记录、清空已完成。
     · 双击完成的记录可直接打开文件；失败/停止的记录可双击打开所在目录。
  提示：
  · m3u8 下载依赖 N_m3u8DL-CLI。程序会自动检测；找不到时可点击「指定 N_m3u8DL」手动选择，路径会记在 dist\settings.ini。也可将 N_m3u8DL-CLI_v3.0.2.exe 放到 dist、dist\lib 或项目根目录的 lib 文件夹中。
  · 直接下载依赖 ffmpeg；部分需要登录、Referer/Cookie 或特殊协议的链接可能无法直接下载。

【常见问题】
  · 合并失败、日志出现 codec not supported：把「合并方式」换成「音频转 AAC」或「全部重编码」。
  · 提示 Invalid data found：源文件没下载完整，重新下载后再合。
  · 提示 Permission denied / could not open：文件被别的程序占用（比如正在播放），关掉占用它的程序再试。
  · 合出来没有声音：确认选的「音频文件」是对的，时长应该和视频接近。
  · 合并很慢：选「直接复制」最快；「全部重编码」视分辨率和时长可能要几分钟。

【支持的格式】
  视频：mp4 mkv mov flv avi webm ts m4v wmv mpg mpeg 3gp
  音频：m4a aac mp3 wav flac ogg opus wma ac3 eac3 amr mka ape
  动图：gif（格式转换页支持作为输入，也可作为输出生成无损调色板 GIF）
  输出：MP4（推荐）/ MKV / MOV / AVI / WEBM；纯音频 MP3 / M4A / WAV / FLAC；GIF 动图
